# Carlson Private Capital Partners — Portfolio Intelligence

This repository publishes a self-contained, static Portfolio Intelligence dashboard for a three-company public-information demonstration. The application is in `index.html`; it requires no build step, runtime server, remote scripts, or external assets.

## Disclosure

The dashboard is dated September 16, 2026 and uses publicly verifiable company identity and profile facts. All undisclosed financial, ownership, valuation, operating, close, and planning values are deterministic synthetic assumptions for a public-information demonstration. Detailed schedules are model-derived, are not reported actuals, and should not be used for investment, accounting, governance, lending, or operational decision-making without replacement by validated source records.

*This is research and reporting analysis only, not personalized financial advice.*
